# Grand Axis Group Ltd — Frontend Demo

Premium, responsive property and machinery website concept for Nairobi, Kenya. Illustrative listings and photos; not verified live inventory.

## Running it

Open `index.html` (or serve the folder with any static host). All CSS and JavaScript are inline; photography lives in `assets/` (`name.webp` full size, `name-sm.webp` for cards and thumbnails). Deploy `index.html` together with the `assets/` folder.

## Highlights

- Refined navy, champagne-gold and ivory palette with Cormorant Garamond headings and Manrope body text.
- Photo previews: every listing card has a swipeable 4–5 photo carousel and a photo-count button that opens a full-screen viewer. Detail pages show a photo mosaic with a lightbox, thumbnails and keyboard navigation.
- Realistic page loading: a branded preloader on first visit, then a gold progress bar and loading screen on every navigation while the next page's images preload. Pages fade in, and sections reveal as you scroll. Users who prefer reduced motion get shorter, motion-free loading.

**Note:** Enquiry forms are demo-only and do not send or store submissions. Replace sample listings and stock photography with approved inventory and connect a secure enquiry service before commercial use.
