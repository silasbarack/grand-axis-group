# Grand Axis Group Ltd — Frontend Demo

Responsive property and machinery website concept for Nairobi, Kenya. Illustrative listings and photos; not verified live inventory.

Open `index.html` for the self-contained website. All CSS, JavaScript, and demo imagery are embedded in one file for easy deployment.

**Note:** Enquiry forms are demo-only and do not send or store submissions. Replace sample listings with approved inventory and connect a secure enquiry service before commercial use.
